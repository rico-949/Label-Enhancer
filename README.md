# Label-Enhancer

This plugin adds the player's ACID to the left of the player's callsign. It updates the label in the chat and in the simulator.

## Install the Plugin in GeoFS

> **WARNING:** You must install the Tampermonkey browser extension before you use this plugin.

Download Tampermonkey from:

https://www.tampermonkey.net/

1. Install the Tampermonkey extension.
2. Make sure that the Tampermonkey icon appears to the right of the browser address bar.
3. Select the Tampermonkey icon.
4. Select **Add new script**.
5. Open the `plugin.js` file.
6. Copy all of the code from `plugin.js`.
7. Paste the code into the Tampermonkey script editor.
8. Press **Ctrl + S** to save the script.
9. Start GeoFS, or reload GeoFS if it is already open.

The plugin is now ready to use.

## Notes

- This plugin requires the Tampermonkey browser extension.
- If the plugin does not start, make sure that the Tampermonkey extension is enabled and that the script is saved correctly.
